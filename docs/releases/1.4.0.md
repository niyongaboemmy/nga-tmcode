**TMCode 1.4: Codex and every AI extension open properly, and all your AI tools sit under one AI icon.** OpenAI's Codex extension now starts in TMCode, and an AI panel that is still loading says so. Your AI tools (TMCode AI, Claude Code, Codex, Gemini Code Assist, Cline, Continue…) share one AI icon with the open one highlighted. Right-click any icon to hide it, as in VS Code.

### AI extensions open properly

- **Codex starts.** OpenAI's Codex extension showed "Codex could not start" after 30 seconds. The cause was in TMCode: messages from an extension reached its page without the page's own origin, so Codex ignored all of them. They now arrive as they do in VS Code, and Codex, Claude Code, Gemini Code Assist, Cline and Continue were each checked in the real app, also after the extensions restart (which happens when you install one).
- **"Starting…" while a panel loads.** An AI panel shows "Starting Codex…" (or whichever tool) until its page is ready, instead of an empty box. A panel that never starts says what went wrong on its page, with Reload, Show Log and Show It Anyway.
- **The model menu opens at once.** "Which AI answers" no longer waits for TMCode to check whether Claude Code, Codex and Gemini CLI are installed; one still being checked says so.
- **Problems are in the log.** What goes wrong on an extension's page (a script error, a file that doesn't load, something its security policy blocks) is written to Output › Extension Host with the extension named.

### All AI tools under one icon

- **One AI icon** in the activity bar for every AI tool. It shows the tool you used last; click it for the AI Tools menu, with the open tool highlighted and where each one opens.
- **The secondary side bar** has one AI switcher in place of a tab per AI tool, showing the tool that is open there.
- **Prefer one icon each?** Turn off "One AI Icon for All AI Tools" in the menu, by right-clicking the activity bar, or in Settings (Activity Bar: Group AI Tools).

### Your activity bar, your way

- **Right-click any icon › Hide**, as in VS Code. The right-click menu lists every icon with a check mark, so you can bring a hidden one back, and Reset Activity Bar shows them all again.
- **The secondary side bar's tabs** can be hidden the same way.
- A hidden view is still one click away (the AI Tools menu, the Command Palette, View menu), and the icon of the view that is open always stays.
