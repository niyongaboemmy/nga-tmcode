**TMCode 0.13: feels like VS Code underneath.** The editor's depth catches up with its looks: code intelligence across files, Replace in Files, real menus, editor grids and terminal profiles.

### Code intelligence
- **Go to Definition opens other files** (F12, ⌘/Ctrl-click, Peek), and **Go Back / Go Forward** returns (⌃- / ⌃⇧- on macOS, Alt+← / Alt+→ elsewhere).
- **TypeScript and JavaScript know the whole project,** following your `tsconfig.json` or `jsconfig.json` (paths, baseUrl, jsx…). Imports of unopened files resolve, and Rename and Find References cover every file.
- **Python intelligence with Pyright:** TMCode offers to download it the first time you open a Python file (it needs Node.js on the computer). Completions, errors, hover, Go to Definition and Rename. In exams it runs only when the teacher allows editor help.

### Finding and changing things
- **Quick Open:** `main.py:12` jumps to line 12; `@` lists the file's symbols; `?` lists the modes. Matching uses the whole path, and recent files come first.
- **The command palette includes the editor's own actions** with their shortcuts.
- **Replace in Files** with a preview, per match or all at once; files to include and exclude; `.gitignore` respected. Local History keeps every file as it was.
- **Search results, Problems and tabs work with the keyboard.**

### Menus and shortcuts
- **New Selection and Run menus,** a fuller Go menu, shortcuts shown in menus, and unavailable items greyed out. The macOS menu bar matches the in-app menus.
- **Everyday shortcuts:** Ctrl+Tab between recent editors, ⇧⌘T Reopen Closed Editor, ⌘1/2/3 editor groups, ⌘N New Text File, Save As, Revert File.
- **Change any shortcut** in Keyboard Shortcuts (double-click a row, press the keys). Conflicts are shown; Reset restores the default. Locked during exams.

### Editor groups and tabs
- **Split Down as well as Right,** up to 8 groups; drag a tab to an edge to split.
- **Pin tabs:** pinned tabs stay left and are never replaced by a preview.
- **Your layout comes back** when you reopen a folder: splits, tabs, pins, cursor positions and sizes.

### Explorer and files
- **Select several files** (Shift, ⌘/Ctrl-click) to delete, copy or move them together.
- **Drag files in from Finder or File Explorer.**
- **Compact folders** (`src/main/java/com/school` on one row), the open file revealed automatically, and type to jump to a name.
- **`.git` is hidden** and can't be deleted or renamed.
- **Files keep their encoding:** files saved in Windows encodings (accents in French files, for example) are no longer damaged when you save them. Reopen or Save with Encoding from the status bar.
- **Status bar pickers** for indentation (spaces or tabs, convert), line endings, encoding and language.

### Terminal
- **Choose your shell:** zsh, bash and fish on macOS and Linux; PowerShell, Command Prompt, Git Bash and WSL on Windows. Pick a default in Settings.
- **Split terminals side by side** and rename them.

### Settings
- **Open Settings (JSON)** with checking as you type.
- **Settings per language:** `"[python]": { "editor.tabSize": 4 }`.
- **The teacher's `.vscode/settings.json`** in a starter folder applies, and shows on a Workspace tab.

### Source control
- **Merge conflicts:** Accept Current, Accept Incoming, Accept Both or Compare, right above each conflict.
- **Stage or revert one change** from the gutter or the diff editor; Previous/Next Change and Inline view in diffs.
- **Git commits appear in the Timeline** next to Local History.

### Safety and accessibility
- **Do you trust this folder?** TMCode asks before running tasks, debug configurations or dev servers from code you cloned. Never for Task Mentor folders or exams.
- **⌘= / ⌘- zoom the whole window,** and a screen reader mode for the editor (⇧⌥F1).
